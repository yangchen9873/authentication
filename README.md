# 身份验证器浏览器扩展

一个本地优先的 TOTP（RFC 6238）浏览器扩展。它生成 6 位、SHA-1、30 秒周期的验证码，不需要后端服务。

## 功能

- 扫描当前网页中的 TOTP 二维码。
- 手动新增单个 Base32 密钥。
- 批量导入 `otpauth://totp/...` 链接或固定格式账户。
- 复制验证码，并尝试填充当前页面的验证码输入框。
- 编辑模式下拖动调整账户顺序、删除账户。
- 导出为可再次导入的 `otpauth://` 文本备份。

## 安装

1. 打开 Chrome 或 Edge 的扩展管理页。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本项目目录。
4. 修改代码后，在扩展管理页点击“重新加载”；扫码脚本更新后还需要刷新目标网页。

## 导入格式

批量导入每行一条，可使用以下任一格式：

```text
otpauth://totp/Google:user%40example.com?secret=JBSWY3DPEHPK3PXP&issuer=Google
Google | user@example.com | JBSWY3DPEHPK3PXP
```

手动新增仅要求填写有效的 Base32 密钥；颁发者和账户可留空。

## 安全说明

账户数据和 TOTP 密钥保存在 `chrome.storage.local`。导出的备份文件也包含密钥，务必加密保存，避免上传、分享或提交到版本控制。若密钥曾暴露在不可信环境中，请在对应服务中轮换它。
